# Java Library Object Model

![Java CI](https://github.com/aaminter/dz15/actions/workflows/ci.yml/badge.svg)

Учебная объектная модель библиотеки на Java.

## Реализовано
- `Author` и `Book`;
- композиция и инкапсуляция;
- конструкторы и перегрузка;
- изменение года издания и вывод данных о книге.

## Запуск
Требуется JDK. Запустите класс `Main` в IntelliJ IDEA.

Учебный пример ООП, не полноценная система библиотечного учёта.
